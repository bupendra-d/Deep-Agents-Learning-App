# Python Guidelines
- Prefer simple, readable and runnable Python.
- Use clear variable and function names; add type hints when useful.
- Explain the key idea briefly before or after code.
- Handle expected errors; avoid broad `except` blocks unless re-raising.
- Use `pathlib` for file paths and environment variables for secrets.
- Do not add dependencies when the standard library is sufficient.
- When debugging, explain the cause and show the smallest practical fix.
